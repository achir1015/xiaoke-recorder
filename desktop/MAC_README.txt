小柯機器人螢幕錄製工具 — Mac 第一次開啟

1. 把「小柯機器人螢幕錄製工具」拖到「應用程式」資料夾。
2. 這個 App 沒有向 Apple 付費簽章，第一次開啟請：
   在「應用程式」裡對 App 按右鍵 →「打開」→ 再按「打開」。
   如果仍被擋住，打開「終端機」貼上：
     xattr -rd com.apple.quarantine "/Applications/小柯機器人螢幕錄製工具.app"
3. 第一次錄影時，請到「系統設定 → 隱私權與安全性」允許：
   ・螢幕與系統錄音（螢幕錄製）
   ・輔助使用（記錄游標與點擊，才能做游標特效與跟隨縮放）
   ・麥克風、相機（需要時）
   允許後請把 App 完全結束再重開。
4. 錄系統聲音：Mac 需要先安裝免費的虛擬音訊裝置 BlackHole（https://existential.audio/blackhole/），
   並在「音訊 MIDI 設定」建立「多重輸出裝置」（喇叭＋BlackHole），App 就會自動使用。

更新：App 內有新版時按「立即更新」，會下載並打開新版安裝映像，把 App 拖進「應用程式」取代即可。
