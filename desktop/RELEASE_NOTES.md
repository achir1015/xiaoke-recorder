## 下載安裝

| 平台 | 下載哪個檔案 | 安裝方式 |
|---|---|---|
| **Windows 10／11** | `XiaokeRecorder-Setup-版本.exe` | 雙擊執行 → 下一步。不需要系統管理員權限 |
| **Mac（M1／M2／M3／M4）** | `XiaokeRecorder-mac-AppleSilicon-版本.dmg` | 打開 → 拖進「應用程式」→ 第一次按右鍵「打開」 |
| **Mac（Intel）** | `XiaokeRecorder-mac-Intel-版本.dmg` | 同上 |
| **Linux（任何發行版）** | `XiaokeRecorder-linux-x86_64-版本.AppImage` | `chmod +x` 後直接執行 |
| **Ubuntu／Debian** | `xiaoke-recorder_版本_amd64.deb` | `sudo apt install ./xiaoke-recorder_版本_amd64.deb` |
| **iPad／iPad Pro／手機** | 不用下載 | Safari 打開 https://achir1015.github.io/xiaoke-recorder/ →「分享」→「加入主畫面」 |
| **線上版** | 不用下載 | https://achir1015.github.io/xiaoke-recorder/ （Chrome／Edge／Safari） |

已安裝的桌面版會自動檢查新版本，按「立即更新」即可。
